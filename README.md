# Interstellar - Omarchy Theme (Singularity Edition)

An Interstellar / black-hole / accretion-disk inspired Omarchy theme for your Arch Linux / Hyprland setup.

### 🎨 Theme Aesthetic
The "Singularity" edition is refined using color analysis from the provided Interstellar wallpapers:
* **Deep space darkness** for focus.
* **Warm accretion disk gold** for highlights.
* **Cold bluish/white glows** for a futuristic sci-fi UI.

### 📌 Singularity Color Palette
- **Backgrounds:** 
    - `#050508` (The Deep Void - Black Hole Core)
    - `#0B0E14` (Main Background - Deep Space)
    - `#161B29` (Surface Panels - Endurance Interior)
- **Foreground:** 
    - `#E0E2EA` (Main Text - Starlight White)
    - `#8F95A5` (Muted Text - Nebula Dust)
- **Accents:**
    - `#FFCC66` (Accretion Gold)
    - `#FF8C42` (Orange Heat)
    - `#7AA2F7` (Cosmic Blue)
    - `#97F1FB` (Soft Cyan Glow)
    - `#B18CFE` (Singularity Purple)
- **Borders:** `#242B3D`

### 📂 Features
- Consistent styling across **Alacritty**, **Kitty**, **Ghostty**, **Hyprland**, **Waybar**, **Mako**, **Walker**, and **Neovim**.
- Custom highlight overrides for Neovim (Keywords: Purple, Functions: Blue, Strings: Gold).
- Seamless integration with the descriptive-named Interstellar backgrounds.
