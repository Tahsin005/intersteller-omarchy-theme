# Interstellar - Omarchy Theme

An Interstellar / black-hole / accretion-disk inspired Omarchy theme for your Arch Linux / Hyprland setup.

### 🎨 Theme Aesthetic
The theme is designed to evoke the feeling of deep space:
* **Deep space darkness** for focus.
* **Warm accretion disk gold** for highlights.
* **Cold bluish/white glows** for a futuristic sci-fi UI.

### 📌 Primary Color Palette
- **Backgrounds:** `#05060A` (Deep Space), `#0B0D14` (Main), `#121624` (Surface/Panels)
- **Foreground:** `#E6E8F0` (Main Text), `#A9B0C3` (Muted Text)
- **Accents:**
    - `#FFD27D` (Accretion Gold)
    - `#FF9E57` (Orange Heat)
    - `#7AA2F7` (Cosmic Blue)
    - `#B4F9F8` (Soft Cyan Glow)
    - `#C099FF` (Purple Nebula)
- **Status:**
    - `#FF5C5C` (Danger)
    - `#F2C94C` (Warning)
    - `#3DDB84` (Success)
- **Borders:** `#23283B`

### 📂 Features
- Consistent styling across **Alacritty**, **Kitty**, **Ghostty**, **Hyprland**, **Waybar**, **Mako**, **Walker**, and **Neovim**.
- Custom highlight overrides for Neovim (Keywords: Purple, Functions: Blue, Strings: Gold).
- Seamless integration with the provided Interstellar backgrounds.
